日程工作台
怎么装到你的 Mac 上

下面四步照着做就行。第一次打开会被系统拦一下，那是正常的，第 3 步专门讲怎么过。
电脑要求
苹果 MacM1 / M2 / M3 / M4 芯片
系统版本
macOS 12 或更高关于本机里能看到
需要多久
约 3 分钟下载 94MB，看网速

下载安装包
点开下面这个链接，页面右侧有个文件名，点它就开始下载。
下载下来的文件叫 schedule-workbench-1.0.0-mac-arm64.zip，在「下载」文件夹里。
github.com/scy124604-source/schedule-workbench/releases/latest
2

双击那个 zip，会解出一个带太阳图标的应用。把它拖进左边的「应用程序」文件夹，别直接在下载文件夹里打开。

第一次运行会问你要不要发通知，选「允许」。不允许的话，日程到点不会提醒你，其余功能照常。

装着不顺利？看这里

提示「应用已损坏，无法打开」
不是真的坏了，是下载时被系统加了隔离标记。打开「终端」（在启动台里搜"终端"），把下面这一行整段复制进去，回车，输密码：
xattr -dr com.apple.quarantine /Applications/日程工作台.app
注意：中间有个空格，是从 /Applications 前面那个空格开始，整行别漏。
双击之后图标跳一下就没了，什么也没发生
说明第 3 步没做对，系统其实把它拦下来了。回到「应用程序」，右键 →「打开」，重来一次。
我的 Mac 是 Intel 芯片的（2020 年以前买的）
这个版本跑不了，会直接报错。看「关于本机」里芯片那一行，写的是 Intel 就不行。告诉我，我单独给你打一个。
我的日程数据存在哪？会不会传到网上
全部存在你自己电脑里，路径是 ~/Library/Application Support/ScheduleWorkbench/。软件不联网、不需要注册，也不会上传任何内容。想备份就把这个文件夹拷走。
